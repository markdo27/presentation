LIQUID.FONT / HOW THE IDEA FORMED

01
WHAT I WANTED

I wanted the soft, swollen shapes of Y2K liquid type, with letters I could keep reshaping.

02
WHY IT WAS HARD

Drawing each letter by hand made every revision slow. My first blur experiment gave me an image, but no useful font workflow.

03
THE ACTUAL BRIEF

“Let me control how much the letters melt, then export a font I can actually type with.”

One shared set of controls gave the alphabet a consistent feel.

VINAFONT / THE PROBLEM

Ế Ộ Ữ
Ơ Ư Ằ Ẵ

Vinafont composes 135 characters using eight accent shapes, with a separate stroke for Đ.

You find a typeface you love. Then you type Vietnamese and discover the letters you need are missing.

The horn on ơ and ư is especially tricky. It joins the letter itself, so its shape and position need to feel at home.

I wanted a browser tool that could find the missing marks, place them, and let me proof the result locally.

VINAFONT / WHAT IT CANNOT DO

Vinafont makes a starting draft. The letters still need a designer’s attention, especially when their accents come from another family.

01
NO KERNING SURVIVES

This export pipeline loses kerning, hinting, variable axes and colour tables. Those limits matter when you take a mock-up into production.

02
CHECK THE FONT LICENCE

The app displays the font’s embedded licence information. Check the actual licence before modifying or sharing the font.

03
WHERE THE DRAFT IS USEFUL

Use the output for proofing and mock-ups, then refine the letters with a type designer. The benchmark helps show where that work is needed.
